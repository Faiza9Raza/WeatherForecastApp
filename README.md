🌦️ Weather Forecast Dashboard
A sleek, real-time weather dashboard built with vanilla JavaScript, demonstrating modern API integration and a fully responsive UI.

Core Features
Live Weather Data: Instantly fetch current weather for any city worldwide.

5-Day Forecast: Plan ahead with a clear, multi-day forecast.

Geolocation: Find weather for your current location with a single click.

Responsive Design: Looks great on any device, from mobile to desktop.

Tech Stack
Front End: HTML5, CSS3 (Flexbox & Grid), Vanilla JavaScript (ES6+)

APIs: OpenWeatherMap API, Browser Geolocation API

Tooling: Asynchronous fetch(), async/await

🚀 Get Started
Clone the repo: git clone https://github.com/your-username/your-repo.git

Get a free API key from OpenWeatherMap.org.

Add your key to the script.js file.

Open index.html and start exploring!
